# Support

If you run into a problem with Pinterest LocalBoard, use one of these paths:

- Open an issue: <https://github.com/thetejasagrawal/Pinterest-LocalBoard/issues>
- Repository: <https://github.com/thetejasagrawal/Pinterest-LocalBoard>

## When Reporting A Problem

Include:

- the Pinterest board URL, if it is public, or a note that it is a private board
- what you expected to happen
- what actually happened
- your Chrome version
- the extension version
- whether the board contains sections
- whether `Single ZIP` or `Smart parts` was selected
- the ZIP part number where the export stopped, if applicable
- whether `_download_report.json` was created inside the ZIP

## Common Fixes

- Reload the extension in `chrome://extensions`
- Refresh the Pinterest board tab once
- Open the board feed instead of an individual pin page
- Use `Smart parts` for large boards; interrupted runs resume at the next
  unfinished part for up to seven days

## Security Reports

Do not post sensitive security issues publicly. See [SECURITY.md](SECURITY.md).
